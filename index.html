Featured project

MindBridge

A full-stack campus mental health platform for students at African universities, where institutional counseling support is often limited. Students track their mood anonymously, journal privately, support each other in an anonymous forum, access wellness resources, flag crises and chat with an AI wellness companion.

Demo video coming soon

No admin can ever identify which student submitted what. Enforced at the data layer, not just the API.Core design principle

Privacy architecture

StudentSigns in with standard auth and uses the app.
APIuser_id never appears in responses. Admin access to journals is structurally blocked.
DatabaseMood data is keyed by anon_token only, with no identity column.
MindBotGroq · Llama 3.3-70B. Conversations are not stored server-side.

Features and how each protects privacy

Mood check-in

Daily 1–5 mood and energy score with an optional note.

🔒 Stored with anon_token only, never user_id

Private journal

Create, read, update and delete personal entries.

🔒 Admin access structurally blocked

Anonymous forum

Post and reply using auto-generated animal names.

🔒 user_id never appears in API responses

Crisis flagging

Low, medium and high severity alerts for counselors.

🔒 No identity column in the database

Resource library

Articles, hotlines and coping exercises.

🔒 Admin-managed, readable by all users

MindBot AI chat

24/7 AI wellness companion powered by Groq (Llama 3.3-70B).

🔒 Conversation not stored server-side

Profile

Update name, university and avatar.

🔒 Standard authentication
